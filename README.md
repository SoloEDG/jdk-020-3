
## 运营机制

- **磨损**：车辆按「行驶」与「作业」分别累计磨损，磨损越高，随机故障概率越大。
- **风险提示**：界面只给概率区间，不预告故障时刻；磨损低于阈值时显示「未达阈值」，
  表示不会因随机因素故障，但磨损仍在增长。
- **随机故障**：途中故障为行驶系故障，必须呼叫拖救；作业中故障多为设备故障，
  已完成成果可交替代车接续，离港仍要求替代车真实完成。
- **拖救与通道**：拖救车、机务车与普通保障共用一条机坪通道，最多两车同时通行；
  故障车停在通道内会阻断通行，直到被拖走或自行驶离。
- **维修区**：两个工位、两条机务车、有限备用件。预防检修主动消除磨损，但占用
  工位与备用件；故障抢修可紧急插队，插队时会向原排队车辆说明预计延期。
- **存档**：只接受完整一致的快照。故障车不会被恢复成空闲，备用件有单调账本，
  重复领取或不一致的存档会被拒绝而不是被悄悄修正。
